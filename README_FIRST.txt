LOCAL LIFE WINDOWS DEPLOYMENT
=============================

NORMAL USE:

1. Extract this whole ZIP.
2. Power the Raspberry Pi and connect both cameras.
3. Double-click LocalLife.exe.

When finished, double-click LocalLife_Stop.exe.

If startup fails, double-click LocalLife_Check.exe.

For full instructions open HOW_TO_RUN.txt.

Do not open or edit the app folder during normal use.
